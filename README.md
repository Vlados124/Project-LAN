# Project LAN CRM

CRM для лидов Project LAN. Это обычный сайт, Claude для работы не нужен. Каждый входит по своему email, а изменения видны всем сразу.

- **Сайт:** GitHub Pages, бесплатно.
- **База, вход и real-time:** Supabase, бесплатный тариф.
- **Что внутри:** проверка новых лидов с оценкой, воронка-канбан, таблица со всеми лидами, дела на сегодня, метрики, импорт из Google Таблицы и выгрузка в CSV.

## Файлы

| Файл | Что это |
|---|---|
| `index.html` | сама CRM |
| `config.js` | адрес базы и ключ, заполняете вы |
| `supabase/schema.sql` | создаёт таблицы и доступы |

---

## Шаг 1. База в Supabase (≈5 минут)

1. Зайдите на **supabase.com**, нажмите Start your project и войдите через GitHub.
2. Нажмите **New project**. Укажите имя `lan-crm`, придумайте пароль базы и сохраните его. Регион выберите **Central EU (Frankfurt)**, он ближе всего к Москве.
3. Когда проект создастся, откройте **SQL Editor** → **New query**.
4. Откройте `supabase/schema.sql`. Внизу в блоке `insert into public.members` впишите email коллеги и начальника вместо примеров: уберите `--` в начале строк. Вставьте весь файл в редактор и нажмите **Run**.

## Шаг 2. Аккаунты для команды

1. Откройте **Authentication** → **Users** → **Add user** → **Create new user**.
2. Введите email и временный пароль, поставьте галочку **Auto Confirm User**.
3. Повторите для себя, коллеги и начальника. Каждый потом сможет сменить пароль в CRM: «Настройки» → «Мой пароль».
4. Для защиты откройте **Authentication** → **Sign In / Providers** → **Email** и выключите **Allow new users to sign up**. Тогда зарегистрироваться сам никто не сможет.

> Доступ закрыт двумя замками: нужно иметь аккаунт **и** состоять в списке `members`. Если не выполнить хотя бы одно, человек не увидит ни одного лида.

## Шаг 3. Подключить сайт к базе

1. В Supabase откройте **Project Settings** → **API** (иногда раздел называется *Data API* / *API Keys*).
2. Скопируйте **Project URL** и ключ **anon public**.
3. Вставьте их в `config.js`:

```js
window.LAN_CONFIG = {
  SUPABASE_URL: "https://xxxx.supabase.co",
  SUPABASE_ANON_KEY: "eyJhbGciOi..."
};
```

Ключ `anon` можно хранить на сайте открыто, Supabase так и задуман. Данные защищает вход и список `members`. Никогда не вставляйте ключ `service_role`.

## Шаг 4. Выложить на GitHub Pages

1. На github.com нажмите **New repository**, имя `lan-crm`, тип **Public**. GitHub Pages бесплатно работает только с публичными репозиториями. В коде нет ни одного лида, данные лежат в Supabase за паролем.
2. Нажмите **uploading an existing file** и перетащите все файлы из этой папки, включая папку `supabase`. Затем **Commit changes**.
3. Откройте **Settings** → **Pages**. В блоке **Branch** выберите `main` и `/ (root)`, нажмите **Save**.
4. Через 1–2 минуты сверху появится ссылка вида `https://ВАШ-ЛОГИН.github.io/lan-crm/`. Отправьте её команде вместе с логинами.

> ⚠️ Репозиторий публичный. Никогда не кладите в него выгрузки с лидами, CSV или SQL с данными клиентов — только код.

## Как добавить человека позже

1. Authentication → Users → Add user (с Auto Confirm).
2. SQL Editor:
   ```sql
   insert into public.members (email) values ('novyi@example.ru');
   ```

Чтобы закрыть доступ, удалите пользователя в Users и выполните `delete from public.members where email = '...';`.

## Резервная копия

«Все лиды» → «Выгрузить CSV». Файл открывается в Excel и Google Таблицах.

## Если что-то не работает

- **«CRM не настроена».** Не заполнен `config.js`, или файл не загрузился на GitHub.
- **«Неверный email или пароль».** Проверьте, что пользователь создан с галочкой Auto Confirm.
- **Вход работает, но лидов нет.** Email не добавлен в `members` (шаг 1.4 или «Как добавить человека»).
- **Изменения коллег не появляются сами.** Заново выполните `schema.sql`: там включается real-time. Повторный запуск безопасен.
- **Сайт не открывается без VPN.** В России сервисы Supabase и GitHub Pages иногда работают нестабильно. В таком случае CRM можно перенести на российский хостинг, например Yandex Cloud.

## AI-оценка

Сейчас оценка ставится вручную: кнопки «Горячий / Тёплый / Холодный» или число 0–100 в карточке лида. В коде уже есть место для автоматической оценки. Её можно подключить позже через YandexGPT или GigaChat, для этого нужен платный API-ключ и небольшая серверная функция в Supabase.
